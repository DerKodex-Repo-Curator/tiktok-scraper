How to get a cookies file
  1. Install the Get cookies.txt LOCALLY extension for Chrome. (Firefox alternative: Get cookies.txt LOCALLY)
  2. Open tiktok.com in your browser and log in normally.
  3. Click the extension icon, then click "Export" to download a cookies.txt file.
  4. Save the file somewhere on your computer (e.g. C:\Users\you\Downloads\tiktok-cookies.txt).
  5. Enter the full path to that file in the field above and click Save.

The cookie file contains your TikTok session. Keep it private and treat it like a password.
